# FAQ-pagina Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tweetalige FAQ-pagina op `/[locale]/faq` met 9 vragen, native accordion, FAQPage JSON-LD, links in nav/footer, sitemap-entry.

**Architecture:** Content leeft volledig in `messages/{nl,en}.json` (namespace `faq`), bewaakt door `verify:i18n`. De pagina is een async server component naar het patroon van `app/[locale]/about/page.tsx` en rendert native `<details>/<summary>` (geen client-JS). JSON-LD wordt gebouwd door een pure functie in `lib/structured-data.ts` en gerenderd via het bestaande `JsonLd`-component.

**Tech Stack:** Next.js 15 App Router (RSC), next-intl, Tailwind v4 (tokens uit `app/globals.css`), vitest + @testing-library/react.

**Spec:** `docs/superpowers/specs/2026-07-10-faq-page-design.md`

## Global Constraints

- Elke nieuwe translation key in **beide** `messages/nl.json` én `messages/en.json` — `pnpm verify:i18n` faalt anders (CI-gate).
- SEO-metadata alleen via `metadataFor(path, key)` uit `lib/page-metadata.ts`.
- JSON-LD-builders alleen in `lib/structured-data.ts`; renderen via `components/JsonLd.tsx`.
- Geen deprecated API's; geen client component tenzij noodzakelijk (hier: niet nodig).
- Package manager: `pnpm` (pnpm 9, Node 20).
- README.md bijwerken in **dezelfde commit** als de nieuwe route — pre-commit hook `readme-check` blokkeert anders.
- **Commits: alleen door Jorick.** Bij elke commit-stap: staged files + commando tonen, wachten op Jorick.

```ts
export type FaqItem = { question: string; answer: string };

// Builds the schema.org FAQPage JSON-LD for the FAQ page. Pure + testable.
// Note: Google shows FAQ rich results only for gov/health sites since 2023;
// the schema still helps AI assistants and crawlers parse the answers.
export function buildFaqJsonLd(items: FaqItem[]) {
  return {
    '@context': 'https://schema.org',
    '@type': 'FAQPage',
    mainEntity: items.map((item) => ({
      '@type': 'Question',
      name: item.question,
      acceptedAnswer: { '@type': 'Answer', text: item.answer },
    })),
  };
}
```

- [ ] **Step 3: Implementation** — create `app/[locale]/faq/page.tsx`:

```tsx
import { setRequestLocale, getTranslations } from 'next-intl/server';
import Link from 'next/link';
import { JsonLd } from '@/components/JsonLd';
import { buildFaqJsonLd, type FaqItem } from '@/lib/structured-data';
import { metadataFor } from '@/lib/page-metadata';
import type { Locale } from '@/i18n/routing';

export const generateMetadata = metadataFor('/faq', 'pages.faq');

export default async function Faq({ params }: { params: Promise<{ locale: Locale }> }) {
  const { locale } = await params;
  setRequestLocale(locale);
  const t = await getTranslations('faq');
  const items = t.raw('items') as FaqItem[];

  return (
    <main className="px-6 py-16 sm:py-20">
      <div className="mx-auto max-w-3xl">
        <JsonLd data={buildFaqJsonLd(items)} />
        <h1 className="text-brand-deep text-3xl font-bold sm:text-4xl">{t('title')}</h1>
        <p className="text-text-soft mt-3 text-lg">{t('intro')}</p>
        <div className="divide-border-subtle border-border-subtle mt-12 divide-y border-y">
          {items.map((item) => (
            <details key={item.question} className="group py-4">
              <summary className="text-text-primary flex cursor-pointer list-none items-center justify-between gap-4 font-medium">
                {item.question}
                <span
                  aria-hidden
                  className="text-text-muted transition-transform group-open:rotate-90"
                >
                  ›
                </span>
              </summary>
              <p className="text-text-soft mt-3 text-sm leading-relaxed">{item.answer}</p>
            </details>
          ))}
        </div>
        <p className="text-text-soft mt-10">
          {t('ctaLabel')}{' '}
          <Link
            href={`/${locale}/contact`}
            data-testid="faq-contact-link"
            className="text-brand font-medium hover:underline"
          >
            {t('ctaLink')}
          </Link>
        </p>
      </div>
    </main>
  );
}
```
