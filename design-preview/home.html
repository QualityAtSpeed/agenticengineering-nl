1.1Basic, twee dagen

Twee dagen hands-on adoptie. Iedereen levert een feature op.

Voor wie
  • Hele DevOps-teams: developers, QA / testers, ops / platform.
  • Gemengde teams die agentic workflows samen adopteren.
  • Engineering managers die met hun team meetrainen.
Vereisten
  • Vertrouwd met git en de command line.
  • Schrijft features in minimaal één taal (TS, Python, Go, etc.).
Wat je leert
  • Lever een werkende feature op een starter repo, met tests, hooks en CI groen vanaf minuut één.
  • Herken failure modes van AI-gegenereerde code in je eigen werk.
  • Oefen test-first met een agent zonder schijnpassende tests te schrijven.
  • Zet hooks en quality gates op die de volgende sprint overleven.
  • Gebruik bestaande MCP servers in echte workflows.
  • Stap naar buiten met een governance-starter die je team echt kan gebruiken.

Curriculum, dag 1: Quality engineering met agents

  1. Agents in je SDLC: waar ze passen, waar ze breken.
    • Waar een agent zijn plek verdient in de SDLC, en waar niet.
    • Wat een agent is vs. chat vs. automatisering.
    • Quality stakes: elke agent-wijziging is code die in productie komt.
  2. Failure modes van AI-gegenereerde code.
    • Hallucinaties, stille regressies, false-green builds.
    • Scope drift en onaangekondigde rewrites.
    • Hoe je ze herkent voordat ze in productie staan.
  3. Test-first met agents.
    • De TDD-loop met een agent als driver.
    • Wanneer tests vóór code komen, wanneer niet, waarom het uitmaakt.
    • Tests die gedrag bewijzen vs. tests die het model tevreden stellen.
  4. Hooks en quality gates.
    • Pre-commit checks: lint, format, type-check.
    • Quality gates die de sprint overleven.
    • Wat de agent NIET mag merge'en.

Curriculum, dag 2: Agent mechanics + capstone

  1. MCP servers in productie-workflows.
  2. Capstone, ochtend: lever een feature op een starter repo.
  3. Capstone, middag: review en governance-starter.
